# ARTIBOT v2.1 — 발표 가이드
### AI 코딩 어시스턴트를 더 똑똑하게 만드는 플러그인

---

# 1. Artibot이란 무엇인가?

## AI 코딩 도구를 위한 두뇌 확장 플러그인

- Claude Code에 설치하는 **플러그인** — 마치 스마트폰에 앱을 설치하듯
- AI 코딩 어시스턴트가 **혼자** 일하는 것을 → **팀으로** 일하도록 전환
- 사용할수록 **스스로 배우고 진화**하는 학습 시스템
- 복잡한 작업을 자동으로 전문가 팀에게 **분배하고 검토**

> 발표 노트: Artibot은 Claude Code라는 AI 코딩 도구 위에 설치되는 플러그인입니다. 일반적인 AI 도구는 한 명의 AI가 모든 것을 처리하지만, Artibot은 28명의 전문 AI 직원이 협력하는 구조로 전환시킵니다. 스마트폰에 앱을 설치하면 기능이 추가되는 것처럼, Artibot을 설치하면 AI 코딩 도구가 훨씬 강력해집니다.

---

# 2. 핵심 기능 1 — 28명의 전문 AI 직원

## 마치 28명의 전문가로 구성된 회사처럼

- **아키텍트** — 시스템 설계 전문가
- **프론트엔드/백엔드 개발자** — 화면과 서버 개발 전문가
- **보안 감사관** — 코드 취약점 검토 전문가
- **마케팅 전략가, SEO 전문가** — 콘텐츠와 검색 최적화 전문가
- 총 **28개 역할**, 각자의 전문 영역에만 집중

> 발표 노트: 일반 AI 도구는 한 명의 직원이 회계도 하고, 디자인도 하고, 법무도 하는 구조입니다. Artibot은 각 분야의 전문가 28명을 두고, 작업 성격에 따라 적합한 전문가를 자동으로 배정합니다. 보안 검토가 필요하면 보안 전문가가, 성능 최적화가 필요하면 성능 엔지니어가 투입됩니다.

---

# 3. 핵심 기능 2 — 팀 자동 배정 (Team Auto-Apply)

## 복잡한 작업은 자동으로 팀이 꾸려집니다

- 사용자가 복잡한 요청을 입력하면 → **자동 감지**
- 독립적으로 처리 가능한 작업으로 **자동 분해**
- 적합한 전문 AI들이 **동시에 병렬 처리**
- 작업 완료 후 **교차 검증** — 서로의 결과를 확인

> 발표 노트: 예를 들어 "새로운 기능을 추가하고 테스트와 문서도 작성해줘"라고 요청하면, Artibot이 자동으로 이것을 3개의 독립 작업으로 나눠 개발자, 테스터, 문서 작성자 AI가 동시에 작업합니다. 사람이 팀을 구성할 필요 없이 자동으로 최적의 팀이 꾸려집니다.

---

# 4. 핵심 기능 3 — 자기 진화 학습 루프

## 사용할수록 더 똑똑해지는 5단계 파이프라인

- **1단계** — 세션 시작 시 과거 경험 자동 로딩
- **2단계** — 작업 중 패턴과 인사이트 실시간 수집
- **3단계** — 세션 종료 시 배운 내용 압축 저장
- **4단계** — 새로운 규칙과 기술 자동 업데이트
- **5단계** — 다음 세션에 개선된 지식으로 재시작

> 발표 노트: 일반 AI 도구는 매번 새로운 대화를 시작할 때 아무것도 기억하지 못합니다. Artibot은 매 세션이 끝날 때 배운 내용을 저장하고, 다음 세션에 그 경험을 바탕으로 더 나은 조언을 제공합니다. 마치 경험이 쌓이는 숙련된 직원과 같습니다.

---

# 5. 핵심 기능 4 — 크로스 컴퓨터 지능 공유

## 모든 사용자의 경험이 하나의 지식 풀로

- **내 PC**에서 배운 것 → **GCP 클라우드**에 익명으로 공유
- 전 세계 사용자들의 **베스트 프랙티스 자동 수집**
- 내 프로젝트에 **맞춤화된 글로벌 인사이트** 자동 적용
- 3단계 학습: **프로젝트 → 내 PC → 글로벌**

> 발표 노트: 혼자 사용하면 내 경험만 쌓이지만, Artibot은 모든 사용자의 경험을 익명으로 통합해서 더 빠르게 진화합니다. 한 사용자가 발견한 효율적인 방법이 전체 커뮤니티에 자동으로 전파됩니다. 물론 공유는 완전히 선택적이며 개인 정보는 보호됩니다.

---

# 6. 핵심 기능 5 — 커스텀 플러그인 SDK

## 나만의 전문가 AI를 만들 수 있습니다

- 우리 회사 전용 규칙과 기술을 가진 **커스텀 에이전트** 생성
- **SDK 제공** — 개발 지식 없이도 설정 파일로 구성
- 업종별, 프로젝트별 **특화된 AI 팀** 구성 가능
- 기존 28개 에이전트에 **추가 확장** 형태로 적용

> 발표 노트: 예를 들어 금융 회사라면 "금융 규제 준수 검토" 전문 에이전트를, 의료 스타트업이라면 "HIPAA 준수 검토" 에이전트를 직접 만들어 팀에 추가할 수 있습니다. Artibot의 SDK는 이런 커스터마이징을 가능하게 합니다.

---

# 7. 핵심 기능 6 — 스마트 파이프라인 (토큰 절약)

## 더 적은 비용으로 더 많은 작업을

- AI 사용량(토큰) 자동 최적화 — **불필요한 반복 제거**
- 중요도에 따라 **Opus vs Sonnet 모델 자동 선택**
- 컨텍스트 압축으로 **장기 대화 효율화**
- 비용 대비 성능 최적 조합 **자동 계산**

> 발표 노트: AI 도구는 사용량에 따라 비용이 발생합니다. Artibot의 스마트 파이프라인은 복잡한 작업에는 고성능 모델(Opus)을, 단순한 작업에는 경량 모델(Sonnet)을 자동으로 배정해 비용을 절감합니다. 불필요한 중복 처리도 자동으로 제거됩니다.

# 9. 작동 원리 — 한눈에 보는 흐름

## 세션 시작부터 종료까지 자동화된 사이클

```
[세션 시작]
     ↓
과거 지식 자동 로딩
(이전 학습 내용 + 글로벌 베스트 프랙티스)
     ↓
[작업 요청 접수]
     ↓
단순 작업?  → 단일 전문가 AI 처리
복잡 작업?  → 팀 자동 구성 → 병렬 처리 → 교차 검증
     ↓
[세션 종료]
     ↓
학습 내용 압축 → 로컬 저장 → 클라우드 익명 공유
     ↓
[다음 세션] → 더 향상된 AI로 재시작
```

> 발표 노트: 이 흐름을 보면 Artibot이 단순한 플러그인이 아니라 하나의 완결된 학습 시스템임을 알 수 있습니다. 매 세션이 이전 세션의 경험 위에 쌓이며, 사용자는 별도의 설정 없이도 이 모든 과정이 자동으로 진행되는 것을 경험합니다.

# 10. 경쟁 비교 — Artibot vs 다른 플러그인

## 왜 Artibot인가?

| 구분 | Cursor Rules | Codex Agents | .clinerules | Windsurf | **Artibot** |
|------|-------------|--------------|-------------|----------|-------------|
| 학습 능력 | 고정 규칙 | 없음 | 없음 | 없음 | **자기 진화** |
| 팀 협업 | 단일 AI | 단일 에이전트 | 단일 AI | 없음 | **28인 팀** |
| 세션 간 기억 | 없음 | 없음 | 없음 | 제한적 | **영구 기억** |
| 교차 검증 | 없음 | 없음 | 없음 | 없음 | **자동 검증** |
| 글로벌 학습 | 없음 | 없음 | 없음 | 없음 | **크로스 공유** |

> 발표 노트: 경쟁 도구들은 정적인 규칙 파일이거나 단일 에이전트 방식입니다. Artibot의 핵심 차별점은 세 가지입니다. 첫째, 스스로 배우고 진화합니다. 둘째, 28명의 팀이 협업합니다. 셋째, 세션이 끝나도 배운 내용이 사라지지 않습니다.

# 11. 경쟁 비교 — 상세 분석

## 도구별 한계와 Artibot의 해결책

- **Cursor Rules**: 개발자가 직접 규칙을 작성해야 함 → Artibot은 **자동으로 규칙을 발견하고 업데이트**
- **Codex Agents**: 한 번에 한 에이전트만 동작 → Artibot은 **28개가 동시 병렬 처리**
- **Generic .clinerules**: 프로젝트마다 처음부터 작성 → Artibot은 **글로벌 지식 자동 적용**
- **Windsurf**: 팀 모드 없음, 결과 검증 부재 → Artibot은 **팀 + 교차 검증 자동화**

> 발표 노트: 다른 도구들이 "설정"에 집중한다면, Artibot은 "학습과 협업"에 집중합니다. 개발자가 규칙을 직접 관리할 필요 없이 AI 스스로 최적의 방법을 찾아냅니다.

# 12. 숫자로 보는 Artibot

## 검증된 규모와 신뢰성

- **28개** 전문화된 AI 에이전트
- **48개** 내장 명령어 (커맨드)
- **98개** 고유 스킬 항목
- **4,912개** 자동화 테스트
- **0개** 테스트 실패 (100% 통과율)
- **5단계** 자기 진화 파이프라인
- **3단계** 학습 레이어 (프로젝트 → PC → 글로벌)

> 발표 노트: 4,912개의 테스트 케이스가 모두 통과한다는 것은 단순한 숫자가 아닙니다. 이것은 Artibot이 다양한 상황에서 일관되고 예측 가능하게 동작한다는 신뢰의 증거입니다. 엔터프라이즈 환경에서 요구되는 안정성 기준을 충족합니다.

# 13. 비용 구조 — 서버 비용 제로

## GCP Cloud Run 기반 무료 운영

- **Google Cloud Run** 서버리스 아키텍처 활용
- **무료 티어** 내에서 운영 — 추가 서버 비용 없음
- 사용량 기반 스케일링 — 과부하 걱정 없음
- 클라우드 지능 공유도 **추가 비용 발생하지 않음**

> 발표 노트: 많은 AI 플러그인이 월정액 구독을 요구하거나 별도 서버 비용을 부담시킵니다. Artibot의 글로벌 학습 공유 서버는 Google Cloud Run의 무료 티어로 운영되므로 사용자에게 추가 비용이 발생하지 않습니다.

# 14. 개인 정보 보호 — 4중 보안 체계

## 공유하되, 절대 노출되지 않는 설계

- **완전 선택적 공유** — 클라우드 공유는 사용자가 직접 켜야 작동
- **SHA-256 익명화** — 모든 식별 정보 암호화 처리
- **PII 자동 제거** — 이름, 이메일, 경로 등 개인 정보 자동 탐지·삭제
- **차등 프라이버시** — 라플라시안 노이즈 추가로 역추적 불가

> 발표 노트: 개인 정보 보호는 Artibot 설계의 핵심 원칙입니다. 공유되는 것은 "패턴과 구조"이지 "실제 코드나 데이터"가 아닙니다. 차등 프라이버시 기법은 구글, 애플 같은 빅테크 기업들이 사용자 데이터를 안전하게 집계할 때 사용하는 동일한 방법론입니다.

# 15. 도입 시나리오 — 실제 활용 예시

## Artibot 없이 vs Artibot으로

**Before (일반 AI 도구)**
- 개발자가 복잡한 기능 요청
- AI 혼자 처음부터 끝까지 처리
- 매번 동일한 실수 반복
- 검토 없이 결과 제공

**After (Artibot)**
- 개발자가 복잡한 기능 요청
- 자동으로 팀 구성 (아키텍트 + 개발자 + 테스터)
- 과거 학습 기반으로 같은 실수 반복하지 않음
- 교차 검증 후 신뢰도 높은 결과 제공

> 발표 노트: 실제로 "로그인 기능 + 테스트 + API 문서 + 보안 검토"를 한 번에 요청하면, Artibot은 이것을 4개 작업으로 분해하고 적합한 4명의 AI 전문가가 동시에 작업합니다. 순차 처리 대비 시간이 4분의 1로 줄어듭니다.

# 16. 요약 — Artibot이 만드는 차이

## 세 가지 핵심 가치

1. **더 빠르게** — 28인 팀의 병렬 처리로 개발 속도 향상
2. **더 똑똑하게** — 매 세션 학습으로 누적되는 지능
3. **더 안전하게** — 교차 검증과 4중 보안으로 신뢰성 확보

> 발표 노트: Artibot은 단순히 AI를 더 많이 쓰는 것이 아니라, AI를 더 잘 조직화하고, 배우게 하고, 협업하게 만드는 시스템입니다. 개발자의 경험을 자산으로 만들고, 그 자산이 팀 전체와 커뮤니티에 공유되는 선순환 구조를 만듭니다.
