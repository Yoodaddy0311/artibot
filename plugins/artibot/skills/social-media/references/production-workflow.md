# Production Workflow Reference

**Core: Every social post passes through a 12-phase pipeline. No phase is optional; each has a gate that must pass before the next phase begins.**

## Phase Detail

### Phase 1: Brief
- **Owner**: Campaign manager
- **Duration**: 1-2 hours
- **Inputs**: Business objective, target audience definition, budget (if paid amplification planned)
- **Activities**: Write content brief specifying goal, KPIs, platform targets, brand constraints, and deadline
- **Outputs**: Signed-off content brief document
- **Gate**: Stakeholder approval on goals, audience, and success metrics

### Phase 2: Research
- **Owner**: Content strategist
- **Duration**: 2-4 hours
- **Inputs**: Content brief
- **Activities**: Scan trending topics on target platforms, audit competitor recent posts, pull hashtag volume data, review content pillar balance
- **Outputs**: Research summary with hashtag shortlist, trend notes, competitor insights
- **Gate**: At least 3 competitor posts analyzed; hashtag volumes verified via platform tools

### Phase 3: Draft
- **Owner**: Copywriter
- **Duration**: 2-4 hours per platform
- **Inputs**: Research summary, brand voice guidelines
- **Activities**: Write platform-specific copy, draft visual concepts/briefs for design, create thread/carousel outlines
- **Outputs**: Draft posts per platform with media direction
- **Gate**: All posts within character limits; CTA present in each; mapped to content pillar

### Phase 4: Internal Review
- **Owner**: Brand manager + compliance reviewer
- **Duration**: 1-2 hours
- **Inputs**: Draft posts
- **Activities**: Check brand voice consistency, fact-check claims, review regulatory compliance (#ad disclosures, copyright), run Content Quality Checklist
- **Outputs**: Approved drafts or revision requests with specific feedback
- **Gate**: 2 independent reviewers approve; zero open compliance flags

### Phase 5: Asset Creation
- **Owner**: Designer / video editor
- **Duration**: 4-8 hours
- **Inputs**: Approved drafts with media briefs
- **Activities**: Create images at platform-specific dimensions, edit video clips, build carousel slides, add captions/subtitles
- **Outputs**: Final media assets per platform
- **Gate**: Correct dimensions verified; accessibility checks pass (alt text, captions, contrast)

### Phase 6: Platform Optimization
- **Owner**: Social media manager
- **Duration**: 1-2 hours
- **Inputs**: Final copy + assets
- **Activities**: Attach UTM parameters to all links, finalize hashtag placement, set emoji strategy, shorten URLs, verify final character counts
- **Outputs**: Platform-ready post packages
- **Gate**: UTM parameters attached and tested; character counts within limits including hashtags

### Phase 7: Schedule
- **Owner**: Social media manager
- **Duration**: 30 minutes
- **Inputs**: Platform-ready posts
- **Activities**: Set publish times based on platform best-time data and audience analytics, queue in scheduling tool
- **Outputs**: Scheduled queue with confirmed times
- **Gate**: Each post queued within its platform's optimal posting window

### Phase 8: Publish
- **Owner**: Scheduling tool (automated) or social media manager (manual)
- **Duration**: Automatic
- **Inputs**: Scheduled queue
- **Activities**: Posts go live per schedule
- **Outputs**: Live posts on each platform
- **Gate**: Spot-check that posts rendered correctly (images loading, links working, formatting intact)

### Phase 9: Monitor
- **Owner**: Community manager
- **Duration**: Ongoing (first 60 minutes critical)
- **Inputs**: Live posts
- **Activities**: Track real-time engagement (likes, comments, shares, saves), watch for negative sentiment, flag any rendering issues
- **Outputs**: Engagement log for first 60 minutes
- **Gate**: First-hour engagement at or above platform baseline; no rendering issues unresolved

### Phase 10: Engage
- **Owner**: Community manager
- **Duration**: Ongoing (48 hours active window)
- **Inputs**: Comments, mentions, DMs triggered by posts
- **Activities**: Reply to comments, answer questions, share UGC, join related conversations, thank sharers
- **Outputs**: Community interaction record
- **Gate**: All comments addressed within 2 hours; negative sentiment escalated per crisis protocol

### Phase 11: Report
- **Owner**: Analytics lead
- **Duration**: 2-3 hours
- **Inputs**: 7-day engagement data from all platforms
- **Activities**: Pull KPIs (reach, impressions, engagement rate, clicks, conversions), compare to benchmarks and prior campaigns, identify top/bottom performers
- **Outputs**: Campaign performance report
- **Gate**: Report delivered within 48 hours of campaign end; all KPIs populated

### Phase 12: Archive
- **Owner**: Content manager
- **Duration**: 30 minutes
- **Inputs**: Performance report + all assets
- **Activities**: Tag assets by pillar, platform, performance tier, and campaign; store in content library; log A/B test results
- **Outputs**: Archived campaign folder with tagged assets
- **Gate**: All assets tagged and searchable; test results documented

## Quick Checklist

- [ ] Content brief signed off
- [ ] Research summary with 3+ competitor posts analyzed
- [ ] Drafts within character limits with CTAs
- [ ] 2 reviewers approved, zero compliance flags
- [ ] Assets at correct dimensions with accessibility
- [ ] UTM parameters attached and tested
- [ ] Posts queued in optimal time windows
- [ ] Posts live and rendering correctly
- [ ] First-hour engagement monitored
- [ ] Comments addressed within 2 hours
- [ ] Performance report delivered within 48 hours
- [ ] Assets archived and tagged
