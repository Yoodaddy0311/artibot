# Market Research (시장 조사)

## When This Skill Applies

- 신규 시장 진입 또는 신제품 출시 전 시장 타당성을 검증해야 할 때
- 목표 고객 세그먼트의 니즈·태도·행동을 정량·정성적으로 파악해야 할 때
- 설문 설계, 심층인터뷰(IDI), 집단인터뷰(FGI) 등 리서치 방법론 선택 및 설계가 필요할 때
- TAM/SAM/SOM 기반 시장 규모 산정 및 성장성 분석이 필요할 때
- 소셜 리스닝·트렌드 데이터로 소비자 인식 변화나 신흥 트렌드를 포착해야 할 때
- 경쟁 환경·포지셔닝 전략 수립을 위한 시장 인텔리전스가 필요할 때

## Core Guidance

### 1. 시장 조사 프로세스

```
Research Goal 정의 -> 조사 방법 선택 -> 데이터 수집 -> 분석 -> 인사이트 도출 -> 보고서 작성 -> 의사결정 반영
```

| 단계 | 핵심 산출물 | 주의사항 |
|------|-----------|---------|
| Research Goal 정의 | 리서치 브리프 (목적·질문·기준) | "알고 싶다"가 아닌 "결정하기 위해 필요하다"로 목적 구체화 |
| 조사 방법 선택 | 방법론 매트릭스 | 예산·일정·목적에 맞는 방법 조합 결정 |
| 데이터 수집 | 원시 데이터 (설문 응답·인터뷰 기록·스크래핑 결과) | 편향 통제, 샘플 대표성 확인 |
| 분석 | 교차분석·코딩·클러스터링 | 정량은 통계 검증, 정성은 주제 코딩 |
| 인사이트 도출 | 인사이트 카드 (발견→의미→기회) | "사실"과 "해석"을 분리해서 기록 |
| 보고서 작성 | Executive Summary + 데이터 부록 | 의사결정자 관점에서 권고안 명시 |
| 의사결정 반영 | 전략 문서 업데이트·가설 목록 | 리서치가 어떤 결정을 바꿨는지 추적 |

### 2. 조사 방법론 비교

| 방법 | 유형 | 강점 | 약점 | 적합한 목적 |
|------|------|------|------|------------|
| 설문 (Survey) | 정량 | 대표성·통계 검증 가능 | 표면적 응답, 맥락 부족 | 규모·태도·만족도 측정 |
| 심층인터뷰 (IDI) | 정성 | 깊은 맥락·동기 파악 | 비용·시간, 소수 의견 | 동기·장벽·의사결정 과정 탐색 |
| 집단인터뷰 (FGI) | 정성 | 집단 역학·언어 파악 | 집단 편향·지배적 발언자 | 아이디어 발굴·개념 테스트 |
| 관찰 조사 (Ethnography) | 행동 | 실제 행동 파악 (말 vs 행동 격차 해소) | 규모 제한·비용 | UX 개선·구매 행동 분석 |
| 소셜 리스닝 | 2차/정성 | 자연 발화·실시간 | 노이즈 많음·맥락 결여 | 브랜드 인식·트렌드 신호 포착 |
| 경쟁사 분석 | 2차/정량 | 효율적·저비용 | 가정 의존·공개 데이터 한계 | 포지셔닝 전략·벤치마크 |
| 패널 데이터 | 2차/정량 | 시계열 추적·규모 | 구독 비용·세그먼트 제한 | 시장 점유율·구매 패턴 |

### 3. 설문 설계 원칙

#### 질문 유형별 사용 가이드

| 유형 | 척도/형식 | 적합한 측정 | 분석 방법 |
|------|---------|-----------|---------|
| 리커트 5점/7점 | 1(매우 불만족) ~ 5(매우 만족) | 태도·만족도·동의 수준 | 평균·분산, t-test |
| 시맨틱 디퍼렌셜 | 양극 형용사 쌍 (저렴한 ↔ 비싼) | 브랜드 이미지·포지셔닝 | 프로파일 맵 |
| 객관식 (단일/복수) | 보기 선택 | 행동·선호도·인지 | 빈도·교차분석 |
| NPS | 0-10점 (추천 의향) | 로열티·전반적 만족 | NPS = 추천(9-10) - 비추천(0-6) |
| 순위형 | 1위~n위 선택 | 선호 우선순위 | 평균 순위·콘조인트 분석 |
| 주관식 | 개방형 텍스트 | 예상치 못한 인사이트 | 주제 코딩·텍스트 분석 |

#### 편향 방지 원칙

- **선행 질문 효과 방지**: 민감한 질문(가격·경쟁사 등)은 뒤에 배치
- **유도 질문 금지**: "우수한 품질에 만족하십니까?" → "이 제품의 품질을 어떻게 평가하십니까?"
- **더블 배럴 금지**: 하나의 문항에 두 가지 질문 포함 금지 ("빠르고 저렴한가요?" → 분리)
- **소셜 바람직성 편향 완화**: 익명성 강조, 중립적 언어 사용
- **응답 순서 효과**: 보기 순서 랜덤화 (특히 선호도 항목)

#### 설문 구조 템플릿

| 파트 | 비중 | 내용 |
|------|------|------|
| 도입부 | 5% | 조사 목적·소요 시간·개인정보 활용 동의 |
| 스크리닝 | 10% | 대상자 적격 여부 확인 (연령·직군·사용 경험 등) |
| 핵심 질문 | 60% | 리서치 목적에 직결된 태도·행동·니즈 질문 |
| 디목적 (Deception Purpose) | 15% | 구매 의향·WTP·경쟁사 인지도 등 민감 질문 |
| 마무리 | 10% | 인구통계, 추가 의견, 추가 연구 참여 의향 |

#### 응답률 향상 기법

- 예상 소요 시간 명시 (5분 이하 설문 응답률 3배)
- 진행 표시바(Progress Bar) 제공
- 모바일 최적화 (전체 설문 응답의 60%+ 모바일)
- 인센티브 구조 명확화 (상품권·기프티콘·결과 공유)
- 첫 번째 질문을 쉽고 흥미롭게 설계 (참여 진입 장벽 최소화)

### 4. 시장 규모 산정 (TAM/SAM/SOM)

#### 탑다운 vs 바텀업 접근법

| 접근법 | 방법 | 강점 | 약점 | 활용 시나리오 |
|--------|------|------|------|-------------|
| 탑다운 (Top-Down) | 전체 시장 규모 × 타겟 비율 | 빠름·외부 데이터 활용 | 타겟 비율 가정 의존 | 투자자용 피치·초기 검토 |
| 바텀업 (Bottom-Up) | 잠재 고객 수 × 객단가 × 구매 빈도 | 실제 영업 기반·정교함 | 데이터 수집 시간 | 사업 계획·실행 예산 수립 |

#### TAM/SAM/SOM 계산 워크시트 구조

```
[TAM 계산]
전체 시장 인구/기업 수:     [A]
해당 카테고리 침투율:        [B%]
평균 연간 지출액(객단가):    [C원]
TAM = A × B% × C = [X억 원]

[SAM 계산]
TAM 중 타겟 지역/세그먼트 비율:  [D%]
타겟 사용자 적격 기준 비율:      [E%]
SAM = TAM × D% × E% = [Y억 원]

[SOM 계산]
현실적 시장 점유율 목표 (3년):   [F%]
SOM = SAM × F% = [Z억 원]
```

### 6. 인사이트 도출 방법

#### 어피니티 다이어그램 프로세스

```
1. 모든 발견을 개별 포스트잇/카드에 기록 (1 카드 = 1 발견)
2. 유사 카드 그루핑 (Bottom-up: 이론 없이 시작)
3. 각 그룹에 이름 붙이기 (그룹 내 패턴 명명)
4. 상위 패턴 추상화 (2차 클러스터링)
5. 가장 많이 반복된 3-5개 테마 선별
```

#### 리서치 발견 → 인사이트 계층 구조

| 계층 | 정의 | 예시 |
|------|------|------|
| 발견 (Finding) | 관찰한 사실 | "응답자 73%가 구매 전 3개 이상의 리뷰를 확인한다" |
| 인사이트 (Insight) | 발견의 의미 | "구매 결정 시 또래 검증(peer validation)이 광고보다 신뢰받는다" |
| 기회 (Opportunity) | 인사이트에서 도출된 전략 방향 | "구매 전 단계에서 UGC 리뷰 노출 강화" |
| 가설 (Hypothesis) | 검증 가능한 실행 명제 | "상품 페이지에 리뷰 수 배지 추가 시 전환율 10% 향상" |

#### 인사이트 품질 기준 (3-Check)

| 기준 | 질문 | 통과 조건 |
|------|------|---------|
| 놀라움 (Surprising) | 상식과 다른가? | 팀 내 "몰랐다"는 반응이 1명 이상 |
| 실행 가능성 (Actionable) | 이를 바탕으로 무언가를 바꿀 수 있나? | 구체적 제품·마케팅·가격 변화로 연결 가능 |
| 전략적 연관성 (Relevant) | 핵심 비즈니스 목표와 연결되나? | OKR·KPI 중 하나 이상에 직접 영향 |

## Output Format

```
MARKET RESEARCH REPORT
```
