# 한국 광고·마케팅 법규 레퍼런스

**주의**: 이 문서는 교육 목적의 요약본입니다. 실제 법적 판단은 반드시 전문 법률가에게 확인하세요. 최종 확인: 2026년 4월.

---

## 1. 표시광고법 주요 조항 요약

**정식 명칭**: 표시·광고의 공정화에 관한 법률 (소관: 공정거래위원회)

### 핵심 금지 행위 (제3조)

| 조항 | 행위 유형 | 내용 |
|------|---------|------|
| 제3조 1항 1호 | 허위·과장 광고 | 사실과 다르거나 사실을 지나치게 부풀려 광고 |
| 제3조 1항 2호 | 기만적 광고 | 소비자를 오인하게 할 우려가 있는 광고 |
| 제3조 1항 3호 | 부당 비교 광고 | 부당하게 비교하거나 비방하는 광고 |
| 제3조 1항 4호 | 비방 광고 | 경쟁 사업자 명예 훼손 |

### 사업자 의무 (제4조)

- 광고 내용에 대한 **실증 의무**: 공정거래위원회 요구 시 입증 자료 제출
- 실증 기간: 15일 이내 제출, 미제출 시 허위광고로 간주
- 사업자 스스로 광고 표현의 진실성 사전 확인 의무

### 처벌 규정 (제17조~제21조)

| 처벌 유형 | 기준 | 상한 |
|---------|------|------|
| 과징금 (매출액 기준) | 관련 매출액의 2% | 최대 매출액 2% |
| 과징금 (정액 기준) | 매출액 산정 불가 시 | 5억 원 |
| 시정명령 | 허위광고 중지·정정광고 게시 | - |
| 형사처벌 | 고의·반복 위반 | 2년 이하 징역 또는 1.5억 이하 벌금 |

## 2. 개인정보보호법(PIPA) 마케팅 관련 조항 요약

**정식 명칭**: 개인정보 보호법 (소관: 개인정보보호위원회)

### 마케팅 목적 수집·이용 동의 (제15조, 제22조)

| 항목 | 요건 | 실무 적용 |
|------|------|---------|
| 동의 방식 | 명확한 고지 후 자유로운 동의 | 체크박스 별도 분리 (필수≠선택) |
| 정보 제공 | 수집 목적·항목·보유 기간·거부 권리 | 회원가입 시 팝업 또는 동의서 |
| 동의 거부권 | 마케팅 동의 거부 시 서비스 제공 불이익 금지 | 필수 동의에 마케팅 항목 포함 금지 |
| 아동 (14세 미만) | 법정 대리인 동의 필수 | 생년월일 확인 후 대리인 동의 프로세스 |

### 제3자 제공 vs 업무 위탁 구분 (제17조, 제26조)

| 구분 | 정의 | 동의 요건 |
|------|------|---------|
| 제3자 제공 | 수탁자 외 다른 사업자에게 데이터 전달 (광고 플랫폼 포함) | 별도 동의 필수 |
| 업무 위탁 | 수탁자가 위탁사 지시에 따라 처리 (이메일 발송 대행사) | 개인정보 처리방침 공개로 갈음 가능 |

**실무 주의**: Google Ads·Meta 광고 커스텀 오디언스 업로드는 **제3자 제공** 해당 → 별도 동의 또는 익명화 처리 후 업로드

### 보유 기간 및 파기 (제21조)

- 수집 목적 달성 또는 동의 철회 즉시 파기 원칙
- 마케팅 DB: 미이용 고객 **1년** 경과 시 파기 또는 별도 저장·고지 필요 (2023년 개정)
- 파기 방법: 전자 파일 복원 불가능한 방법, 출력물 파쇄

### 처벌 규정

| 위반 유형 | 처벌 |
|---------|------|
| 동의 없는 수집·이용 | 5년 이하 징역 또는 5,000만 원 이하 벌금 |
| 제3자 무단 제공 | 5년 이하 징역 또는 5,000만 원 이하 벌금 |
| 안전조치 미이행 | 3,000만 원 이하 과태료 |
| 동의 방법 위반 | 3,000만 원 이하 과태료 |

## 3. 정보통신망법 광고 전송 관련 조항

**정식 명칭**: 정보통신망 이용촉진 및 정보보호 등에 관한 법률 (소관: 방송통신위원회)

### 영리 목적 광고성 정보 전송 기준 (제50조)

| 요건 | 내용 |
|------|------|
| 수신 동의 | 전송 전 수신자 동의 획득 필수 |
| 발신자 표시 | 전화번호·이메일 등 실제 연락처 표시 (080 수신거부 번호) |
| 수신 거부 방법 | 무료로 수신 거부 가능한 방법 명시 |
| 야간 광고 제한 | 21:00~08:00 수신 거부 의사 표시한 자에게 전송 금지 |
| 제목 표시 | 이메일 제목에 "(광고)" 또는 "[광고]" 표시 |

### 채널별 야간 발송 규정 비교

| 채널 | 주간 (08:00~21:00) | 야간 (21:00~08:00) |
|------|------------------|--------------------|
| 이메일 | 수신 동의 + 광고 표시 | 별도 야간 발송 동의 필요 |
| SMS/MMS | 수신 동의 + 080 수신거부 | 별도 야간 발송 동의 필요 |
| 앱 푸시 | 수신 동의 | 별도 야간 발송 동의 필요 |
| 카카오 비즈메시지 (광고) | 수신 동의 + 광고 표시 | 별도 야간 발송 동의 필요 |

### 수신 거부 처리 의무

- 수신 거부 요청 시 **3영업일 이내** 처리
- 수신 거부 처리 후 확인 메시지 발송 권고
- 수신 거부자에게 추가 광고 발송 시 **1,000만 원 이하 과태료**

## 4. 체험단·인플루언서 고지의무 공정위 가이드라인 요약

**근거**: 추천·보증 광고에 관한 심사지침 (공정거래위원회, 2023년 개정)

### 경제적 이익 범위

| 유형 | 고지 필요 여부 |
|------|-------------|
| 현금 지급 | 필수 |
| 제품·서비스 무상 제공 | 필수 |
| 할인 혜택·쿠폰 | 필수 |
| 공동 수익 창출 (제휴 링크) | 필수 |
| 개인이 자발적으로 구매한 경우 | 불필요 |

### 고지 방법 기준

| 채널 | 고지 위치 | 인정 표현 | 거부 표현 |
|------|---------|---------|---------|
| 유튜브 | 영상 시작 30초 내 자막 또는 제목 | #광고 #협찬 | #PR (단독 사용) |
| 인스타그램 | 캡션 첫 줄 | #유료광고 #광고 | 해시태그 목록 끝에 숨기기 |
| 블로그 | 게시글 상단 | "이 글은 [브랜드]로부터 협찬을 받아 작성되었습니다" | 본문 하단 소글씨 |
| 틱톡 | 영상 내 자막 또는 캡션 첫 줄 | #광고 | 영상 끝 자막 |
| 팟캐스트 | 광고 구간 시작 | "이 팟캐스트는 [브랜드]의 후원을 받습니다" | 에피소드 설명란만 표시 |

### 광고주 책임 범위

- 광고주는 인플루언서의 고지 여부를 **사전 계약 및 사후 모니터링** 할 의무
- 인플루언서가 고지 누락 시 광고주도 **공동 책임** 적용 가능
- 계약서에 고지 의무 조항 필수 포함 권고

## 6. 위반 사례 및 제재 내역 예시 (교육 목적)

**주의**: 아래 사례는 공정거래위원회·개인정보보호위원회 공개 의결서 기반 교육용 요약입니다.

### 표시광고법 위반 사례

| 사례 유형 | 위반 내용 | 제재 수준 |
|---------|---------|---------|
| 건강식품 과장 광고 | 미인증 성분의 "암 예방" 효능 광고 | 시정명령 + 과징금 수천만 원 |
| 인플루언서 협찬 미고지 | 수십 명의 뷰티 인플루언서 협찬 미고지 대규모 캠페인 | 광고주 과징금 수억 원 + 시정명령 |
| 허위 할인율 광고 | 정상가 부풀린 후 대폭 할인 표시 | 시정명령 + 과징금 + 정정광고 |
| 부당 최상급 표현 | 근거 없는 "업계 1위", "최고의 품질" 광고 | 시정명령 (과징금 없이 종결 多) |

### 개인정보보호법 위반 사례

| 사례 유형 | 위반 내용 | 제재 수준 |
|---------|---------|---------|
| 무단 마케팅 활용 | 서비스 가입 동의만으로 마케팅 문자 발송 | 과태료 수천만 원 |
| 동의 없는 제3자 제공 | 회원 이메일 리스트를 광고 플랫폼에 무단 업로드 | 과징금 + 과태료 |
| 보유 기간 초과 | 탈퇴 회원 마케팅 DB 수년간 미파기 | 시정명령 + 과태료 |

### 정보통신망법 위반 사례

| 사례 유형 | 위반 내용 | 제재 수준 |
|---------|---------|---------|
| 야간 광고 문자 발송 | 수신 동의 없이 새벽 시간대 대량 문자 발송 | 과태료 + 시정명령 |
| 수신 거부 미처리 | 수신 거부 요청 후 계속 광고 발송 | 과태료 |
| 발신자 번호 조작 | 수신 거부를 피하기 위한 번호 변경 발송 | 형사 처벌 (사기) |
