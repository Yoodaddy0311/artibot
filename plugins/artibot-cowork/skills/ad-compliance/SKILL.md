# Ad Compliance (광고 법규 컴플라이언스)

## When This Skill Applies

- 광고 카피·랜딩 페이지·이메일·SNS 콘텐츠 게시 전 법적 리스크 점검이 필요할 때
- 체험단·인플루언서 협찬 캠페인에서 경제적 이익 고지 의무를 확인해야 할 때
- 한국 또는 글로벌 시장 진출 시 국가별 광고·마케팅 법규 차이를 파악해야 할 때
- 개인정보 수집·이메일·SMS·앱 푸시 마케팅 수신 동의 절차를 설계해야 할 때
- 의료·건강·금융 등 규제 강화 업종의 광고 표현 기준을 검토해야 할 때

## Core Guidance

### 1. 한국 광고 법규 핵심

#### 표시광고법 (공정거래위원회)

**금지 행위 유형**:

| 위반 유형 | 설명 | 대표 사례 |
|---------|------|---------|
| 허위·과장 광고 | 사실과 다르거나 사실을 과장한 표현 | "100% 효과 보장", "모든 피부 타입에 완벽" |
| 기만적 광고 | 소비자를 오인하게 할 우려가 있는 표현 | 할인율 부풀리기, 정가 조작 후 할인 표시 |
| 부당 비교 광고 | 객관적 근거 없는 경쟁사 비교 | "경쟁사 대비 2배 효과" (데이터 없음) |
| 비방 광고 | 경쟁 사업자 신용 훼손 | 경쟁 제품 결함 과장 묘사 |
| 부당 표시 | 필수 표시 사항 누락 또는 은폐 | 원산지·제조일자 미표시 |

**필수 표시 항목** (업종별):

| 업종 | 필수 표시 항목 |
|------|-------------|
| 식품·건강기능식품 | 원재료·원산지·유통기한·영양성분·기능성 표시 기준 |
| 화장품 | 전성분·사용기한·제조국·기능성 인증 여부 |
| 전자제품 | 에너지 소비효율 등급, KC 인증 |
| 금융상품 | 이자율(APR)·수수료·원금 손실 가능성 |
| 의료기기 | 허가·신고 번호, 사용 목적, 주의사항 |

**체험단·인플루언서 광고 고지 의무** (2023년 개정 강화):
- 경제적 이익(현금·상품·서비스)을 받은 경우 **콘텐츠 내 명확한 고지** 필수
- 고지 위치: 콘텐츠 시작 또는 제목·첫 화면에서 쉽게 인식 가능한 위치
- 인정되는 표현: "#광고", "#협찬", "#유료광고", "이 콘텐츠는 [브랜드]로부터 제품을 제공받아 작성되었습니다"
- 인정되지 않는 표현: "#PR", "#Thanks to", 해시태그 뭉치 속 은닉
- **위반 시**: 광고주 과징금 최대 매출액 2% 또는 5억 원, 인플루언서 시정명령

#### 개인정보보호법(PIPA) 마케팅 적용

| 항목 | 요건 | 주의사항 |
|------|------|---------|
| 수집 동의 | 마케팅 목적 수집 시 별도 동의 필수 | 이용약관 일괄 동의로 갈음 불가 |
| 목적 구분 | 서비스 이용 동의 ≠ 마케팅 활용 동의 | 체크박스 분리 필수 |
| 동의 철회 | 수신 거부 즉시 처리 (지체 없이) | 거부 처리 확인 메시지 발송 |
| 보유 기간 | 동의 철회 또는 계약 종료 시 즉시 파기 | 법정 보존 기간 있는 경우 예외 |
| 제3자 제공 | 별도 동의 없이 광고 플랫폼에 데이터 전달 불가 | 위탁과 제3자 제공 구분 필수 |

#### 정보통신망법 광고 수신

| 채널 | 의무사항 | 야간 발송 기준 |
|------|---------|-------------|
| 이메일 | 수신 동의, 발신자 정보, 수신 거부 링크 | 야간(21:00~08:00) 별도 동의 필요 |
| 문자(SMS/MMS) | 수신 동의, 080 무료 수신 거부 번호 | 야간(21:00~08:00) 별도 동의 필요 |
| 앱 푸시 | 앱 내 푸시 수신 동의, 설정에서 거부 가능 | 야간 발송 별도 동의 필요 |
| 카카오 알림톡 | 비광고성은 동의 불필요, 광고성은 동의 필수 | 광고성 태그 표시 필수 |

**수신 거부 메커니즘 필수 사항**:
- 이메일: 하단에 "수신 거부" 링크 (1클릭 처리, 재확인 화면 1회만 허용)
- 문자: "080-XXX-XXXX로 수신 거부 문자 발송" 안내 필수
- 수신 거부 처리 후 **3영업일 이내** 반영

#### 전자상거래법 (온라인 쇼핑)

- 청약 철회(7일) 기간·조건을 상품 페이지 및 주문 확인 페이지에 명시
- 통신판매업자 등록번호 사이트 하단 표시 의무
- 에스크로·소비자 피해 보상 보험 가입 표시
- 리뷰·후기 조작 금지 (대가성 리뷰 고지 없이 게시 금지)
- 할인 광고 시 할인 기준 가격(최초 판매가 또는 최근 30일 판매가) 명시

### 2. 글로벌 기준

#### FTC 가이드라인 (미국)

| 항목 | 기준 | 실행 방법 |
|------|------|---------|
| 인플루언서 공개 | 유물질적 연결(material connection) 공개 필수 | #ad, #sponsored, "Paid partnership" 명시 |
| 공개 위치 | 콘텐츠 시작 부분, 스크롤 없이 보이는 위치 | 해시태그 끝에 숨기기 금지 |
| 내돈내산 vs 협찬 | 무상 제공품은 협찬으로 간주 | 단순 샘플 제공도 #gifted 필요 |
| 건강·미용 클레임 | 임상 데이터 없는 효과 표현 금지 | "도움이 될 수 있다(may help)" 등 조건부 표현 |
| 금융 클레임 | 투자 수익 보장 표현 금지 | 과거 수익률 ≠ 미래 수익 보장 명시 |

#### GDPR (유럽)

| 요소 | 요건 | 마케팅 적용 |
|------|------|----------|
| 동의 기반 | 명시적·자발적·철회 가능한 동의 | Pre-checked 체크박스 금지 |
| 목적 제한 | 수집 목적 외 사용 금지 | 뉴스레터 수신 동의 ≠ 광고 타겟팅 동의 |
| 데이터 삭제권 | 요청 시 30일 이내 삭제 | 마케팅 DB에서 완전 삭제 프로세스 필요 |
| 쿠키 동의 | 비필수 쿠키(마케팅·분석) 사전 동의 | 쿠키 배너로 동의 전 추적 불가 |
| 데이터 이전 | EU 외 국가 데이터 이전 시 안전장치 | SCCs 또는 Adequacy Decision 필요 |

#### ASA (영국) 핵심 원칙

| 원칙 | 내용 |
|------|------|
| 정직성 | 광고는 진실하고 오해를 유발하지 않아야 함 |
| 공정성 | 비교 광고는 공정하고 입증 가능한 근거 필요 |
| 명확한 식별 | 광고는 광고로 명확히 식별 가능해야 함 |
| 사회적 책임 | 취약 계층(아동·노인) 보호, 차별 금지 |

### 4. 리스크 등급 분류

| 리스크 | 예시 광고 문구 | 처벌 | 수정 방법 |
|--------|-------------|------|---------|
| HIGH | "100% 효과 보장", "완치 가능" | 시정명령·과징금 최대 5억 | 임상 데이터 기반 조건부 표현으로 변경 |
| HIGH | "최고", "유일한", 근거 없는 1위 표방 | 시정명령·과징금 | 수상 내역·인증 근거 명시 또는 삭제 |
| HIGH | 체험단 협찬 미고지 | 광고주·크리에이터 공동 과태료 | 제목에 #광고 #협찬 추가 |
| HIGH | 개인정보 동의 없는 마케팅 발송 | 3,000만 원 이하 과태료 | 명시적 동의 프로세스 구축 |
| MEDIUM | "임상 실험 결과" (미인증 데이터) | 시정명령 | 인증된 연구 인용 또는 표현 완화 |
| MEDIUM | 이메일 수신 거부 미제공 | 과태료 1,000만 원 이하 | 하단 수신 거부 링크 추가 |
| MEDIUM | 야간 마케팅 문자 별도 동의 없이 발송 | 과태료 | 야간 발송 동의 항목 분리 |
| LOW | 환불 정책 표시 미흡 | 시정 권고 | 상품 페이지 하단 명확 표시 |
| LOW | 이메일 발신자 정보 불명확 | 권고 | 회사명·주소·연락처 추가 |

### 5. 안전한 광고 카피 작성 가이드

#### 검증된 표현 vs 금지 표현

| 카테고리 | 금지 표현 | 안전 표현 |
|---------|---------|---------|
| 효과 보장 | "반드시 효과 있음", "100% 보장" | "임상 연구에서 X% 개선 효과 확인" |
| 최상급 표현 | "최고", "유일한", "업계 1위" | "수상 [대회명·연도]", "고객 만족도 4.8/5" |
| 의학적 클레임 | "치료", "완치", "의학적 효능" | "건강 유지에 도움을 줄 수 있음" (인증 제품만) |
| 수익·투자 | "수익 보장", "안전 투자" | "과거 성과가 미래 수익을 보장하지 않습니다" |
| 비교 우위 | "경쟁사보다 2배 빠름" | "독립 테스트 결과 [출처]에서 [수치] 확인" |
| 희소성·긴박감 | "지금 안 사면 후회" (허위) | "이번 달 한정 00개 수량" (사실 기반) |

#### 의학·건강 광고 주의사항

- **건강기능식품**: 식약처 인증 기능성 범위 내에서만 표현 가능. 인증 문구 ("[기능성 내용]에 도움을 줄 수 있음") 필수
- **의료기기**: 허가·신고된 사용 목적 외 효능 광고 금지. 허가 번호 표시
- **일반 식품**: 질병 예방·치료 표현 절대 금지 ("암 예방", "혈당 개선" 등)
- **화장품**: 의약품적 효능·효과 표현 금지 ("세포 재생", "주름 치료")

#### 금융·보험 광고 주의사항

- 원금 손실 가능성 명시 (투자 상품)
- 수익률 과거 데이터는 미래 보장이 아님을 명시
- 대출 광고: 대출금리 범위(최저~최고), 연체 이자율, 총 대출 비용 명시
- 보험 광고: 보장 내용·제외 사항 동등하게 표현 (작은 글씨 면책 조항 금지)

## Output Format

```
COMPLIANCE REVIEW REPORT
========================
Date:      [YYYY-MM-DD]
Content:   [광고 유형 및 채널]
Reviewer:  [검토자]
Market:    [한국 / 글로벌 / 복수]

RISK SUMMARY
------------
| 항목 | 리스크 등급 | 위반 법규 | 수정 필요 여부 |
```
