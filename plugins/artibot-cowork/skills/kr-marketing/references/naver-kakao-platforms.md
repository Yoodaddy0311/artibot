## 4. 네이버 블로그 최적화 가이드

### 4.1 포스트 구조 권장

| 요소 | 권장 기준 | 근거 |
|------|---------|------|
| 본문 길이 | 최소 1,500자, 2,500~3,500자 최적 | DIA 체류시간 지표 |
| 이미지 | 최소 5장, 10~15장 최적 | 스크롤 깊이 유도 |
| 이미지 비율 | 1:1 또는 3:2 | 모바일 가독성 |
| 영상/움짤 | 1개 이상 권장 | 체류시간 증가 |
| 내부 링크 | 이전 포스팅 2~3개 연결 | C-Rank 활동성 |
| 외부 링크 | 신뢰할 수 있는 1~2개 | DIA 정확성 |
| 태그 | 10~15개, 카테고리 일관성 | 검색 유입 |
| 제목 | 32자 이내, 키워드 앞쪽 배치 | CTR |

### 4.2 C-Rank 향상 주간 운영 체크리스트

| 요일 | 활동 | 목표 |
|------|------|------|
| 월 | 주력 키워드 심층 포스팅 | DIA 품질 스코어 |
| 화 | 이웃 신청 50명 + 답방 댓글 | 영향력 지표 |
| 수 | 사진·짧은 일상 포스팅 | 활동성 빈도 |
| 목 | 주력 키워드 포스팅 2탄 | 주제 집중도 |
| 금 | 서로이웃·댓글 응대 | 반응성 |
| 토 | 주간 요약·큐레이션 | 체류시간 |
| 일 | 인플루언서 챌린지 참여 | 영향력·트래픽 |

### 4.3 검색 상위 노출 체크리스트

| 체크 항목 | 기준 |
|---------|------|
| 키워드 반복 | 본문에 주 키워드 5~8회, 연관 키워드 3~5회 |
| 제목 키워드 | 제목 앞 15자 내에 주 키워드 |
| 첫 문단 | 주 키워드 포함 + 결론 요약(이탈률 감소) |
| 이미지 ALT | 주 키워드 포함(접근성·SEO) |
| 해시태그 | 주 키워드 1순위 + 관련 10~14개 |
| 발행 시간 | 타깃 검색 피크 1~2시간 전(업종별 상이) |
| 48시간 부스트 | 발행 직후 이웃 알림·SNS 공유 |

## 부록: 업데이트 주기 및 출처

- 본 문서는 **2026년 1분기** 기준 공개 자료·업계 평균을 취합한 추정치다.
- 네이버 검색광고 공식 단가·규격은 `searchad.naver.com` 고시를 우선한다.
- 카카오모먼트 소재 규격은 `business.kakao.com/moment` 최신 가이드를 확인한다.
- 업종별 벤치마크는 시즌성·키워드 경쟁도에 따라 ±30%까지 편차가 발생할 수 있다.
