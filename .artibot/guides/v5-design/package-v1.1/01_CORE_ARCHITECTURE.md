# Core Architecture

## v5 definition

> **Intent-first, adaptively routed, artifact-driven autonomous runtime.**

Artibot v5 should understand the user's real goal, preserve it as canonical intent, compile the right execution strategy, route each action to the right level of intelligence, coordinate multiple humans/agents through a single live project state, independently review outcomes, and preserve only meaningful durable artifacts.

## Four foundation pillars

### 1. Intent
What are we actually trying to accomplish?

### 2. Canonical State
What is true right now?

### 3. Intelligence Routing
Which model/topology should handle the next action?

### 4. Artifact Governance
What must be created, updated, archived, promoted, or discarded?
