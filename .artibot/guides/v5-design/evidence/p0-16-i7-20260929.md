- 행의 "남은 조사 = I7" 은 이 문서로 **답이 났다**. 팀원은 문서 명시로, 서브에이전트는 문서와 도구 표면에 근거한 추론으로 답했다. 서브에이전트 부분이 추론 등급이라는 점은 유보로 남긴다.

- P0-16 행에는 I7 과 별개로 batch-2 메모가 남아 있다: "라이브 영수증 확인은 릴리스·`/update` 뒤이며 미측정". 이것이 done 조건에 들어가는지는 **리더가 판정**한다. 이 문서는 I7 만 다룬다. 백로그는 편집하지 않았다.

## 6. 프로브 설계 (실행하지 않음)

서브에이전트 I7-a 를 추론에서 실측으로 올리려면 사람의 조작이 필요하다. `/model` 은 사용자 슬래시 커맨드라서 에이전트가 대신 입력할 수 없기 때문이다.

1. 임시 디렉터리(리포 밖, 훅이 없는 빈 설정)에서 대화형 `claude` 를 연다. 메인 모델은 sonnet 으로 둔다.
2. frontmatter `model: inherit` 인 서브에이전트를 백그라운드로 띄운다. 예: 긴 sleep 루프 도구 호출 여러 턴.
3. 실행 도중 사용자가 `/model opus` 를 입력한다. 그다음 `/tasks` 행의 모델 표기와 그 서브에이전트 transcript 의 이후 assistant 행 `"model"` 을 본다.
4. 음성 대조: 같은 절차를 `/model` 없이 한 번 더 한다. 양성 대조: `/model` 을 입력한 뒤 **새로** 띄운 inherit 서브에이전트가 opus 로 서빙되는지 본다. 이것은 문서 §2-2 가 예측하는 동작이다.

이 프로브는 리포 밖 임시 디렉터리에서 돌린다. 훅이 없으면 Artibot 원장 행은 남지 않는다. 훅이 켜진 설정에서 돌리면 그 세션 행을 원장 exclusions 에 추가해야 한다.

**원장 영향(이번 조사)**: 이번 조사는 `claude -p` 도 프로브 세션도 만들지 않았다. 스캔 스크립트 3개는 파일을 읽기만 한다. 이 세션의 일반 도구 호출은 평소처럼 훅을 거쳤다. 예를 들어 `webfetch-cache` 훅은 `runtime/cache/webfetch/` 에 캐시 파일을 쓴다. 이런 행은 프로브 행이 아니므로 exclusions 대상이 아니다.
